Supported Barcode Types

QR Code

2D code for URLs, text, and data. Supports error correction levels.

EAN-13 / UPC-A

Retail product codes. EAN-13: 13 digits, UPC-A: 12 digits.

EAN-8 / UPC-E

Compact product codes. EAN-8: 8 digits, UPC-E: 6 digits.

Code 128

Full ASCII support for alphanumeric data.

Code 39

Alphanumeric code for industrial use.

Data Matrix

Compact 2D code for small items and labels.

How to Use

1

Select Barcode Type

Click on the barcode type tab (QR Code, EAN/UPC, Code 128, Code 39, or Data Matrix) at the top of the extension window.

2

Enter Data

In the input panel, enter your data:

  • Single barcode: Type one value and click "Generate"
  • Bulk generation: Enter one value per line, then click "Generate All"

The extension validates each entry according to the selected barcode type format.

3

Customize Settings

Adjust settings in the right panel:

  • Format: PNG or SVG
  • Size: Use presets or enter custom dimensions
  • Colors: Set foreground and background colors
  • Text: Configure font, size, alignment, and position
  • Quality: Select DPI (72, 150, 300, 600)

Preview updates automatically as you change settings.

4

Download Barcodes

After generation, download your barcodes:

  • Individual: Click the download button next to each barcode
  • Bulk: Click "Download ZIP" to get all barcodes in a ZIP archive

Files are named automatically with your custom prefix (if set).

Data Format Requirements

QR Code / Data Matrix

Any text or URL (no length limit)

EAN-13

12 digits (checksum calculated automatically)

UPC-A

11 digits (checksum calculated automatically)

EAN-8

7 digits (checksum calculated automatically)

UPC-E

6 digits (compressed UPC-A format)

Code 128

Full ASCII characters (letters, numbers, symbols)

Code 39

Alphanumeric characters (A-Z, 0-9, and some symbols)

Tips

Settings are saved automatically - Your preferences persist between sessions.

Invalid entries are highlighted - Check the results table for error messages.

Use bulk generation for efficiency - Process multiple barcodes at once.

Customize themes - Choose from 10 header and 15 accent color presets.
